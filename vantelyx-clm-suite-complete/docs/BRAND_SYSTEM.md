# Vantelyx CLM Brand System

## Locked product name

**Vantelyx CLM**

Do not use Obliq, OblIQ, TermVista, Contract AI, or any earlier working name in the product UI, package metadata, documentation, Docker services, or API labels.

## Positioning

Vantelyx CLM is an AI contract operations platform for organizations that need more than document storage. It helps teams intake, review, approve, execute, monitor, renew, and audit contracts from one command workspace.

## Tagline

Contracts controlled. Obligations visible. Risk reduced.

## Voice

- Enterprise-grade
- Clear and confident
- Practical, not fluffy
- Evaluator-friendly for RFPs
- Built for legal, procurement, finance, operations, IT/security, and executive users

## Visual direction

- Modern enterprise SaaS
- Deep slate / white base
- Bright blue accent
- Rounded cards
- Clear CTAs
- Dashboard-first command center
- Low-training UX with guided workflows
