# Opstrax SupplyOps v1 Requirements

## Product Promise
Know what you have. Know where it is. Know who touched it. Know what needs action. Know what accounting needs. Keep working even when the network does not.

## Must-Have V1 Workflows

- Low stock detection
- Purchase request creation
- Receiving against purchase request
- Label generation
- Stocking to bin
- Internal department request
- Request approval
- Picklist assignment
- Worker-safe offline picking
- Supervisor sync review
- Item issuing
- Accounting export validation

- Audit timeline
